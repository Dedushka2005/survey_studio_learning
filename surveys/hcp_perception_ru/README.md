  Если таблица окажется громоздкой — заменить на цикл.
- **Q11** — цикл простых вопросов по брендам с «Увеличится» в Q10 (внутри блока категории).

## Проект (поле): CAWI по персональным ссылкам, квоты по городам

- **Ссылки:** короткая ссылка проекта `https://sst.gl/algln1026` + `?extid=<ID>`. 5000 ссылок —
  `tools/make_links.py https://sst.gl/algln1026 5000 surveys/hcp_perception_ru/links/hcp_perception_ru_links_5000.xlsx`
  (файл лежит в репозитории, он же загружен в систему базой контактов — **не перегенерировать**: повторный
  запуск даёт новые ID). ID — 10 случайных символов.
- **База контактов** (своя, от заказчика базы нет) — тот же xlsx: `Rid` — «Поле с данными», `ID` — «Внешний ключ»,
  `Телефон` — «Телефон» (фиктивный, 10000 + Rid), `Ссылка` — «Пропустить».
- **Rid** (служебный вопрос 10) — номер 1–5000 из базы (`contact.data['Rid']`), чтобы быстро найти интервью.
  Нет контакта / нет extid → «Ссылка на опрос недействительна…» (в тестировании без базы вопрос пропускается).
- **Флаги проекта:** «Запрещать запуск анкеты, если отсутствует уникальный идентификатор контакта», «Запрещать
  запуск анкеты, если в базе не найден контакт по extId», «Защита от переполнения квот»; «Время жизни брошенных
  интервью» — 10–15 мин (по умолчанию 3 ч держит место в квоте).
- **Квоты** — счётчик на каждый город S5 (системный номер 108): условие `Q108 = <код> and Result = Completed`,
  условие квоты `Q108 = <код>`, квота — число (жду от пользователя). Плюс общий счётчик `Result = Completed`.
  Сверх квоты не сохраняем; текст — в скрипте «Обработка»: «К сожалению, мы уже набрали достаточное число
  участников. Будем рады Вашему участию в других наших исследованиях!».
